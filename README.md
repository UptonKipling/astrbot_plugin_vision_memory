# 多模态视觉识图与图片记忆管理

**插件标识：** `astrbot_plugin_vision_memory`  
**当前版本：** V1.10.2  
**作者：** UptonKipling  
**适用框架：** AstrBot `>=4.24.1,<6`

本插件用于 AstrBot 聊天机器人场景下的图片识别、参考图管理和图片记忆管理。插件支持视觉模型特征提取、真实参考图二次核验，以及三个图片库的可选 CCIP 辅助核验。

## 一、当前版本功能

### 1. 图片识别触发

- 私聊中收到图片时启动识别。
- 群聊默认要求当前消息真实 @Bot，并带有图片或引用含图消息。
- 引用消息或历史消息中的 @Bot 不会代替当前消息的真实 @Bot。
- Bot 自己发送的图片不会进入识别记忆、图片库或待命名队列。
- 同一事件包含多张图片时，当前版本处理提取到的第一张图片。
- 识别结果会作为临时上下文注入本轮 LLM 请求，但不要求 Bot 必须在最终回复中讨论图片。

### 2. 三个图片库

| 图片库 | 用途 | 默认接受阈值 |
|---|---|---:|
| 预设库（魔裁） | 预置 16 个角色栏目，用于相应动漫人物参考图管理 | 42% |
| 人工视觉添加库 | 由管理员自行创建人物或事物栏目并上传参考图 | 45% |
| Bot 图片库 | 保存经管理员手动命名确认的 Bot 图片记忆 | 45% |

三个库均采用逐张参考图特征，不要求查询图与参考图像素完全一致。预设库（魔裁）更侧重脸部、五官、发型和稳定配饰；其他库综合人物或事物的稳定视觉结构。

### 3. 多阶段识别

1. 调用 AstrBot 已配置的视觉模型提取查询图特征。
2. 根据候选栏目的逐张参考图资料进行第一阶段匹配。
3. 启用“参考图二阶段视觉核验”时，将查询图与候选真实参考图再次提交视觉模型核验。
4. 启用 CCIP 且组件可用时，对三个库中的候选参考图计算 CCIP 距离，并将结果作为辅助核验依据。
5. 根据各库接受阈值确定候选是否被接受，并记录识别日志。

CCIP 主要面向单一动漫人物图像。人工视觉添加库和 Bot 图片库同样支持 CCIP，但普通实物、场景或非动漫图片仍应以视觉模型结果为基础，不应仅凭 CCIP 距离确定身份。

识别分数属于模型生成的视觉证据评分，不是确定概率，也不是生物识别结论。

## 二、安装与升级

### 方式一：通过 AstrBot 安装

在 AstrBot 插件管理界面选择本插件压缩包进行安装，完成后重新加载插件。

### 方式二：通过插件目录安装

将插件解压到：

```text
data/plugins/astrbot_plugin_vision_memory/
```

然后重新加载插件。

从旧版升级时，插件标识和数据目录保持不变，已有图片库数据可以继续使用。升级前仍建议备份插件运行数据。

### 面板入口与版本兼容

本插件同时提供 `views/vision-memory/` 和 `pages/vision-memory/` 两套内容相同的面板目录：AstrBot 4.29 系列及后续版本优先读取 `views/`，旧版本可继续读取 `pages/`。新增或更新面板目录后，请重新加载插件并刷新 WebUI 页面。

- AstrBot 4.29 系列：在侧边栏“扩展功能”分组中打开“插件视图”，找到本插件的 `vision-memory` 视图；也可从本插件详情页进入。
- AstrBot 4.28 系列：从插件管理中的本插件面板入口进入。
- 面板显示名称统一为“多模态视觉识图与图片记忆管理”，内部插件标识仍为 `astrbot_plugin_vision_memory`。

## 三、依赖安装与国内镜像回退

CCIP 为可选组件。插件首次启用且检测不到 `imgutils.metrics` 时，会尝试安装：

- `dghs-imgutils>=0.19.0,<0.20`；
- `pillow`；
- `huggingface-hub`；
- `tqdm`；
- `requests`；
- `packaging`；
- `scipy`；
- `onnxruntime`；
- `opencv-python`，无法使用时回退到 `opencv-python-headless`。

为避免 `dghs-imgutils` 的 `numpy<2` 依赖约束与 AstrBot 核心环境冲突，插件使用 `--no-deps` 安装该组件，再单独安装伴随依赖，不会主动用其依赖约束替换 AstrBot 的 NumPy。

每一项 pip 安装操作均按以下顺序尝试：

1. 当前 pip 配置或默认源；
2. 清华镜像：`https://pypi.tuna.tsinghua.edu.cn/simple`；
3. 阿里云镜像：`https://mirrors.aliyun.com/pypi/simple/`。

安装来源和失败回退情况会写入 AstrBot 日志。所有来源均失败时，插件仍保留视觉模型识别功能，但不会执行 CCIP 核验。

上述镜像回退针对 **pip 依赖包安装**。CCIP 模型文件首次使用时的下载属于独立过程，仍取决于当前运行环境能否访问模型来源。

## 四、初始配置

1. 在 AstrBot 中配置支持图片输入的多模态模型 Provider。
2. 打开本插件的 WebUI 管理页面。
3. 在“视觉模型”区域选择 Provider 并保存。
4. 按实际使用情况设置预设库和其他库的接受阈值。
5. 将“Bot 自身角色名”设置为当前 Bot 使用的角色名称。
6. 根据需要启用参考图二次视觉核验和三库 CCIP 核验。

插件读取 AstrBot 已配置的 Provider，不在本插件页面保存 API Key。

## 五、参考图与栏目管理

### 新建栏目

进入预设库（魔裁）或人工视觉添加库，点击“新建栏目”，输入名称并保存。

### 上传参考图

在栏目卡片中点击“上传图片（可多选）”，或在栏目编辑弹窗中选择图片后点击上传。两处入口均支持一次选择多张图片；插件按选择顺序逐张上传，每张图片仍分别执行服务端校验和特征处理。

上传前会统一检查本轮图片的格式和单张大小，发现不符合要求的文件时不会开始本轮上传。上传过程中，状态栏显示当前图片序号、文件名和已完成数量；文件选择、上传、刷新和页签按钮暂时禁用，避免重复提交或误切换页面。某张图片失败时会继续处理后续图片，全部结束后汇总成功与失败数量，并列出失败文件及原因。

上传成功后，插件会尝试生成每张图片的独立视觉特征；CCIP 可用时也会生成并缓存对应 CCIP 特征。

支持格式：

- JPG / JPEG；
- PNG；
- WebP；
- GIF；
- BMP。

单张上传图片不得超过 20 MB。每个栏目的参考图数量默认最多 24 张，可在配置中调整。

### 查看与重建特征

栏目详情可查看每张参考图的视觉特征、CCIP 缓存状态、模型名称和输入尺寸。点击“重建全部参考图特征”可重新读取三个图片库中的参考图并更新特征，不会主动删除参考图片。

### 删除

- 删除单张图片不会删除所属栏目。
- 删除人工创建的栏目会同时清理该栏目数据。
- 预设库的内置角色栏目会保留栏目槽位，删除时清理其参考图和特征。

## 六、未知图片与 Bot 图片库

当前版本不使用聊天上下文自动命名。

1. 未达到任何库接受阈值的图片会进入“待管理员命名”队列。
2. 插件不会读取用户后续发言、LLM 历史或 Bot 回复来推断图片名称。
3. 管理员在 WebUI 查看原图后，手动输入最终名称并确认入库。
4. 同名栏目已存在时，确认图片会合并为该栏目的新参考图。
5. 待命名图片默认保留 7 天，即 168 小时。
6. 每个会话最多保留 20 张待命名图片，超限时清理最旧图片。
7. 管理员也可以直接删除待命名图片。

Bot 图片库中连续未被重新识别或使用的栏目，默认在 7 天后执行遗忘清理。该期限可通过“Bot 图片库遗忘天数”调整。

## 七、识别日志与运行设置

WebUI 提供以下管理内容：

- 图片库栏目和参考图管理；
- 待管理员命名图片处理；
- 视觉模型选择；
- 接受阈值调整；
- 参考图二次视觉核验开关；
- 三库 CCIP 核验开关及相关参数；
- 识别日志查看；
- Bot 图片库遗忘清理。

识别日志用于记录候选、评分、阈值、CCIP 距离和最终判定，便于检查识别过程。

## 八、数据与使用注意事项

- 图片库、待命名图片和识别数据保存在 AstrBot 的插件数据目录中。
- 公开展示截图或制作登记材料前，应遮盖账号、群组、路径、密钥和个人图片等信息。
- 上传和使用人物、角色或其他图片时，应确保具有相应使用权。
- AstrBot、视觉模型、`dghs-imgutils` 和 CCIP 模型分别适用其原有许可条件。
- 版本更新记录见 `CHANGELOG.md`，供 Bot 遵循的当前行为规则见 `SKILL.md`。
